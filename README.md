# Netflix Clone (HTML & CSS)

# Project Overview
This project is a front-end clone of the Netflix landing page built using pure HTML and CSS. The main goal of this project is to replicate the user interface and design of Netflix while practicing responsive web design and layout structuring.

---

# Features
-  Pixel-perfect UI inspired by Netflix
-  Fully responsive design (mobile, tablet, desktop)
-  Navigation bar with logo and buttons
-  Hero section with background banner
-  Multiple content sections (movies/shows layout)
-  Footer with links and information

---

# Tech Stack
- **HTML5** – Structure of the web page  
- **CSS3** – Styling and layout  
- **Flexbox & Grid** – Responsive layout design

# How to Run the Project
1. Clone the repository:
   ```bash
   git clone https://github.com/riyakamhub15/NetflixClone.git
   ```
2. Open the project folder
3. Run the `index.html` file in your browser

---

# Limitations
- This is a **static UI clone** (no backend functionality)
- No video streaming or authentication features
- No JavaScript interactions
